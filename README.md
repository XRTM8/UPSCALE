# UPSCALE Studio

تطبيق لتحسين الفيديو محلياً، بنواة **Rust** وواجهة **Leptos/WASM + Tauri 2**. العربية افتراضياً مع الإنجليزية، وتصميم فحمي بزجاج ضبابي ونصوص تيتانيوم. لا تُرفع ملفاتك إلى خادم.

هذه أول نسخة عملية للحاسب. المعالجة الحالية تقليدية عبر FFmpeg: تكبير Lanczos، تنظيف ضوضاء اختياري، تعزيز تفاصيل معتدل، وتوليد إطارات اختياري. **نماذج التحسين بالذكاء الاصطناعي والنشر إلى الشبكات الاجتماعية وتطبيقات الهاتف لم تُنفَّذ بعد.** قوالب المنصات هنا إعدادات تصدير؛ لا تضمن جودة عرض معينة بعد ضغط المنصة.

## ما يعمل

- استيراد MP4 وMOV وM4V وMKV وWebM وAVI من نافذة النظام، مع فحص الخصائص بواسطة ffprobe.
- معاينة الأصل، ثم معاينة الملف الناتج والتبديل بينهما بعد التصدير الفعلي.
- قوالب إخراج رأسي وأفقي، وملاءمة الصورة كاملة أو قصها صراحةً، و1080p أو 4K حسب القالب.
- تصدير MP4/H.264/AAC، وتقدم مستمد من FFmpeg، وإلغاء حقيقي للمهمة.
- فحص أبعاد الملف الناتج ومدته ووجود الصوت قبل إعلان الاكتمال.
- حماية المصدر، ورفض الكتابة فوق ملف موجود، وتنظيف الملفات المؤقتة عند الإلغاء والفشل.
- خطوط وأيقونات محلية؛ لا تحتاج الواجهة إلى CDN عند التشغيل.

## التشغيل على Windows

المتطلبات: Windows 10/11 وWebView2 وNode.js 22 أو أحدث وpnpm. لتجهيز أدوات Rust وMinGW وTrunk وFFmpeg داخل `.tools` دون تغيير PATH النظام أو طلب صلاحيات مدير:

```powershell
.\scripts\bootstrap-windows.ps1
.\scripts\dev.ps1
```

يمكن أيضاً استخدام أدوات Rust/MSVC وWindows SDK المثبتة بالطريقة المعتادة مع `rustup target add wasm32-unknown-unknown` وTrunk 0.22.1 وFFmpeg/ffprobe على PATH، ثم:

```powershell
pnpm install --frozen-lockfile
pnpm assets
pnpm tauri dev
```

لإنشاء ملف التطبيق:

```powershell
.\scripts\build.ps1
```

الناتج في `target/release/upscale-studio.exe`. يلزم FFmpeg وffprobe على PATH أو داخل مجلد `tools` بجانب التطبيق. بدلاً من ذلك يمكن تحديد مساريهما بمتغيري `UPSCALE_FFMPEG` و`UPSCALE_FFPROBE`. الأدوات المكتبية لا تُحمّل تلقائياً أثناء تشغيل التطبيق.

للمعاينة في المتصفح فقط: شغّل `trunk serve`. يمكن اختيار فيديو محلي ومعاينته، بينما يُعطّل التصدير لأنه يعتمد على تطبيق الحاسب.

## التحقق

```powershell
.\scripts\check.ps1
```

تحتاج اختبارات خط المعالجة إلى FFmpeg وffprobe. تغطي فحص المصدر والدوران ومعدل الإطارات، وصحة قوالب الإخراج، وتصديراً حقيقياً مع الصوت، وحفظ المصدر، والإلغاء، ومنع استبدال الملفات الموجودة. يوجد أيضاً CLI لاختبار المحرك:

تستخدم اختبارات الواجهة Edge المثبت على Windows، أو المسار المحدد بمتغير `UPSCALE_BROWSER_PATH`. تفحص اللغتين وحفظ التفضيلات والقوالب، و24 حالة عرض ولوحات، واستيراد فيديو محلي فعلي دون الادعاء بتصديره من المتصفح.

```powershell
cargo run -p upscale-core --bin upscale-cli -- probe 'video.mp4'
cargo run -p upscale-core --bin upscale-cli -- export 'video.mp4' 'video_upscaled.mp4'
```

## البنية

| المجلد | المسؤولية |
|---|---|
| `crates/upscale-types` | عقود البيانات المشتركة بين الواجهة والمحرك |
| `crates/upscale-core` | تحليل الفيديو وخطة التصدير والعامل والإلغاء وCLI |
| `crates/upscale-ui` | واجهة Leptos مكتوبة بـRust وتخزين تفضيلات المستخدم |
| `src-tauri` | نافذة الحاسب وحوارات الملفات وصلاحيات المعاينة وربط المحرك |
| `public/assets` | خطوط وأيقونات مع ملفات تراخيصها |
| `scripts` | تجهيز الأدوات والبناء والتحقق |

تصل أوامر المعالجة إلى ملفات اختارها المستخدم، باستخدام معرّفات داخلية. لا تستقبل واجهة التصدير أمراً shell أو مسار مصدر حراً. يُسمح لبروتوكول المعاينة بقراءة ملفات محددة، دون منح وصول عام إلى القرص.

## حدود هذه النسخة والخطوات التالية

تصدير HDR غير مفعّل حتى إضافة مسار ألوان مُختبَر. توليد الإطارات يعتمد على CPU وقد يكون بطيئاً أو يسبب تشوهات؛ يبقى اختيارياً. تُحفظ المهمة في الذاكرة، ولا يوجد استئناف من منتصف الملف بعد إغلاق التطبيق. يحتاج Android/iOS إلى تكامل ملفات ووسائط وعامل معالجة مخصص واختبارات أجهزة فعلية؛ صغر عرض النافذة وحده لا يجعله تطبيق هاتف جاهزاً.

المراحل التالية: دمج نموذج تحسين زمني ومقارنته بعد النشر، وتسريع GPU مع قياسات، وحفظ صف المهام، ثم موصلات النشر الرسمية وتطبيق الهاتف. راجع [الدراسة](FEASIBILITY_AR.md) و[مواصفات الواجهة](DESIGN_AR.md).
