# UPSCALE Studio (Android)

تطبيق أندرويد لتحسين وتجهيز الفيديو محلياً باللغتين العربية والإنجليزية، مبني بالكامل بـ **Kotlin + Jetpack Compose + Media3 + OpenGL ES**. لا تُرفع ملفاتك إلى أي خادم.

> أُرشف إصدار سطح المكتب السابق (Rust / Tauri `0.3.0`) في الفرع `legacy-tauri` والوسم `archive/tauri-v0.3`.

## ما يقدمه الإصدار 0.8.0

- **ترقية محرك المعالجة الفوري (`UpscaleGlEffect`):**
  - نقل تمريرة التحسين إلى الدقة المستهدفة بعد `Presentation` لرفع حدة المقاطع المُكبّرة دون تضخيم البكسلات، مع دقة حسابية `highp` لدعم 4K دون تشوّه.
  - إضافة فلتر **إزالة آثار الضغط (`Deblock`)**، وفلتر **حيوية الألوان المحمية للبشرة (`Vibrance`)**، وأوضاع جاهزة (**طبيعي، نصوص وشاشة، ليلي، سينمائي**).
- **إصلاحات المعاينة والمقارنة السلسة:**
  - إلغاء إعادة تهيئة المشغّل المتكررة أثناء تحريك قصّ الإطار أو قصّ المدة (`Trim`) مع الحفاظ على موضع التشغيل.
  - توحيد إحداثيات خط المقارنة (`Split-Screen`) بنظام `LTR` متطابق مع OpenGL في الواجهة العربية (`RTL`) ومع التكبير (`Zoom`) ووضع `Contain`.
  - إيقاف التشغيل تلقائياً عند تصغير التطبيق، ودعم استقبال الفيديوهات مباشرة عبر **مشاركة إلى UPSCALE** من المعرض والتطبيقات الأخرى.
- **مزايا احترافية جديدة:**
  - **التقاط إطار محسّن (`Frame Snapshot`)** وحفظه مباشرة في `Pictures/UPSCALE`.
  - **سجل التصديرات الأخيرة** مع خيارات العرض والمشاركة وإعادة التحرير.
  - خيار **كتم أو إبقاء الصوت**، وتفعيل **HEVC على دقة 1080p** للأجهزة الداعمة، وسماحية محاذاة مرمّزات العتاد لأبعاد `4:5`.
  - تعريب رسائل الأخطاء وإشعارات التصدير في الخلفية، وعرض ملاحظات الإصدار في المحدّث التلقائي.
- **تحديث تلقائي غير مزعج داخل التطبيق (`AppUpdater`):**
  - فحص هادئ في الخلفية لآخر إصدار رسمي دون نوافذ منبثقة مزعجة.
  - اختيار تلقائي للحزمة المناسبة للجهاز (`arm64-v8a` أو `universal`)، والتحقق من بصمة SHA-256 (مع خطة بديلة من `SHA256SUMS.txt`) ومعرّف الحزمة (`com.xrtm8.upscale`) والشهادة الدائمة قبل التثبيت.

## البناء والتوقيع

المتطلبات: JDK 17 وAndroid SDK (API 36).

```powershell
./gradlew testDebugUnitTest lintDebug assembleRelease
```

لتوقيع حزمتَي الإصدار (`arm64-v8a` و`universal`) والتحقق من الشهادة الدائمة (`com.xrtm8.upscale`، `versionCode = 8000`):

```powershell
.\scripts\sign-release.ps1
```
